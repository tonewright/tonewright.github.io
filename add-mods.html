Add your mods

Add WWMI mods through Timbre: from GameBanana, from an archive or folder, copied in by hand, or a whole XXMI library.

Timbre takes WWMI mods as they are published. As each one lands, Timbre converts it to Overtone's own format, which it calls making it native (what that changes). You do nothing extra.

#From GameBanana

  1. Press Add a mod.
  2. Paste the mod's page link. If the page has several files, pick one.
  3. Press Download.

#From an archive or a folder

For a .zip, .rar or .7z you downloaded, or a mod folder you already have.

  1. Drop it on Timbre's window, or press Add a mod and choose it.
  2. If the archive has a password, Timbre asks for it.
  3. Untick any files you do not want, such as a readme.
  4. Press Import. Each archive reads Unpacking, then Unpacked, and the mods appear once all are done.

To stop a batch, press Cancel while it is unpacking: nothing from it is added. Once it reads Finishing, the mods are going in, and Close only hides the window.

Your archive or folder is left as it was: Timbre copies the mod into the library. A folder holding mods for several characters becomes one mod for each, each under its own character.

#Choices when you add a mod

Choice Default What it does
Enable after install / Enable after import on Turns the mod on as it lands. Off, double-click its tile later.
Name What the mod is called, without its character The folder becomes <Character> - <Name>, such as Chisa - Radiant; Timbre shows Radiant on Chisa's page.
Character The character the mod's files change Files the mod under that character, read from its files, never from the archive's name. From the mod where its files name no one character. Pick one only to file it elsewhere.
Details What the mod's files say The source, author and version the mod states. Change one only to correct it.

A mod whose files name no character goes under its GameBanana page's character, or the character whose page you dropped it on, or under character/others when there is neither.

Dropped on a mod's page, Timbre asks what the archive is:

Dropped Choices
One archive Update this mod (the default) replaces its files; Alternate of it groups the two on one tile; Unrelated mod imports it on its own.
Several archives Unrelated mods (the default) imports each on its own; Alternates of it groups them all with the mod.

To keep the archives you download, turn on Settings → Importing → Keep downloaded archives.

#Copy a folder in by hand

  1. Close the game.
  2. Copy the mod's folder anywhere in your library.
  3. Start Timbre, or restart it if it was open. It converts the mod and, unless you turned Organize mods by character off, moves it to character/<character>/.
  4. Turn the mod on in Timbre.

The first time Timbre finds folders outside their character folders, it asks whether to organize them by character:

  • Organize moves them.
  • Keep as it is leaves every folder where it is.
  • Not now asks again at the next start.

Mods draw the same either way. To always keep your own folders, turn off Settings → Library → Organize mods by character.

#Weapon mods

A weapon mod changes one weapon, whoever holds it. Timbre files one you add alone under weapon/<weapon>/. One that came inside a character's mod stays in that mod's folder and is still a mod of its own. Turning the outfit on turns its weapon on too, and turning the outfit off turns it off. Turn the weapon off alone to wear the outfit without it.

Once your library holds a weapon mod, the top of the library shows Characters and Weapons. Press Weapons to see every weapon with the number of mods on it.

#Bring a whole XXMI library

Native mods no longer load in XXMI, so give Timbre a copy and leave XXMI's folder alone.

  1. Under Settings → Game, press Use beside Suggested library: it makes an empty folder near the game and sets it as your Mods folder. The suggestion shows only while no Mods folder is set; otherwise choose an empty folder of your own as Mods folder.
  2. Copy everything inside your XXMI Mods folder into it.
  3. Open Health. Under New mods, press Describe.
  4. Under Not native yet, press Make native.

Mods whose folder name starts with DISABLED stay off; nothing is renamed. To bring only some mods, import them one at a time as above.

If you set Timbre's Mods folder to XXMI's own Mods folder instead, Overtone still draws those mods but never makes them native, so they cannot be edited in Blender.

#What native means

A native mod is rebuilt once from its own files, instead of being read from its ini files every time it loads.

  • It opens in Blender, and saving there changes it in game (How to create a mod).
  • It keeps working when a game update renumbers the character's bones. An update that changes her model still needs the author's new version.
  • Nothing is deleted: the ini files, and the buffer files they name, move into the mod's .overtone/legacy/ folder. Textures stay where they are.
  • It no longer loads in XXMI.

A mod Timbre cannot convert is listed under Health → Couldn't be made native, with the reason. It still draws as before. Try again appears once a newer Timbre can do something different.

When a new version of a native mod arrives, Timbre imports it, keeps your changes, and makes it native again.

#Where things are

Where What
character/<character>/ That character's mods. Timbre's library shows one page per character.
weapon/<weapon>/ That weapon's mods. Timbre's library shows them under Weapons.
character/others/ Mods whose character is not known yet.
Health → Tidy up No character, Folder names, Downloaded twice, Two folders, one mod and Leftover files.

A mod shows on its character's page even if you keep its folder somewhere else.

Timbre names a mod's folder after its character and the mod, such as Chisa - Radiant, and renames it when you rename the mod or move it to another character. Folder names lists the folders named another way, with the name each would get; Rename renames them all.

A running game shows a new mod a moment after Timbre adds it, with Reload on file change on; F10 reloads every mod (Play with Overtone).

Applies to Timbre 26.1019.0 and Overtone 26.1018.0.
