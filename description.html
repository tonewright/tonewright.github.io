Guides/Make mods

Description reference

Every key a mod's description, overtone.mod.toml, takes, what each one does in game today, what is kept but not drawn yet, and which texture wins.

Reference22 min readTimbre 26.1123.0 · Overtone 26.1123.0

#What a description is

Every mod Overtone draws has one file beside it, overtone.mod.toml, its description. The only code it can bring is a shader (Materials).

Timbre writes it when it imports a WWMI mod or dumps a character. Then it is yours: an update is merged into it, and what you changed stays. Examples: Write a description.

It is TOML, so these mean the same:

[option.Hair.Long]
show = ["Hair 1"]

[option.Hair]
Long.show = ["Hair 1"]

[option.Hair]
Long = { show = ["Hair 1"] }

#Edit it

  • In Timbre. A mod's Inside tab reads the description out; click a row to open the file at that line. A problem is underlined as you type, with a note. Save (Ctrl+S) writes it, and History can undo the save.
  • After an update. See Fix what an import wrote.
  • .overtone/ beside it holds Overtone's own files, your switch positions and backups among them. Never edit them.

Save refuses a file that would not draw, or one changed on disk since you opened it, saying not saved: and why.

#When something is wrong

Kind What happens
Refused The whole mod is not drawn. Timbre's note names the line; the game's log names the mod and why.
Skipped That key or table is ignored and the rest draws. Timbre marks the line; the game's log names it.
Not drawn yet The key is read and kept, and does nothing in game.

The notes Timbre shows:

Note Means
Doesn't read. Not valid TOML. Refused.
Doesn't match its export. A value Overtone cannot read, such as a default that is no choice. Refused.
Made by a newer Overtone. Its format is newer than this Timbre: update Timbre.
Not moved to this version. An older format not brought forward: close other Overtone tools, retry.
Not read. A key Overtone does not know. Skipped; it stays in the file.
Unknown section. A table Overtone does not know. Skipped with all in it.
Stated twice. A table written twice: the later one counts.
Unknown switch. A condition or look names a switch the mod lacks.
Unknown condition. A name no switch or [when] has. Refused in a switch's, rule's, piece's or mesh's when.
Missing texture., Missing file., Missing mesh file. A file is not in the mod's folder.
Wrong size. A mesh file of the wrong size: that mesh is not drawn.
Not drawn. Something that cannot draw as written, such as a piece the model lacks. Skipped.
Check this. Probably not meant, or a key not drawn yet. Draws as written.

#What works today

What In game
Switches, looks, conditions, rules, sliders, expressions Drawn.
Pieces shown, hidden and see-through; the game's parts hidden Drawn.
diffuse, lightmap, normalmap, materialmap, highlight Drawn, where the game draws that part with that kind of texture.
glowmask and the game's effect textures Drawn on parts whose texture the game's tables know; elsewhere the game's stays.
A material's own shader, layers hlsl draws once Timbre has compiled it on Windows; a game_shader needs no compile.
Renders Made by Timbre on Windows with the game closed; until then, and on a Mac or Linux, the file it replaces.
glow, cutoutmap, specialmap Kept, never drawn.
Finishes Drawn on the mod's parts; where and mask not yet.
Every outline, [adjust] Not drawn yet.

#The top of the file

format = 55
id     = "18d3a98a9189469c0053"
name   = "Summer Dress"
object = "carlotta"
Key What it is
format 54. A 24 to 53 is brought to 54 when Timbre opens the library. Refused if missing or any other number.
id Made once by Timbre; loadouts find the mod by it, so it survives a renamed folder. A folder copied whole keeps it, and only one of the two can then be drawn: give the copy any id no other mod uses.
name The mod's name in Timbre and in game. If left out, the folder's name.
object The character or weapon it dresses, as the game's list names it (carlotta, rover). Left out, found from the meshes; a name not in the list files the mod as unknown. Expressions and the game's effect textures need it written.
game Left out, wuwa. zzz is read and edited, never drawn. Any other value is refused.
author, link, about, version Credits, and its version (1.0.0).
folders The mod's own folders, where it has several.
outfit An outfit's mods, by folder, in the order they turn on. It then holds only these top keys; a table refuses it.

#Switches: [option.<name>]

A switch is on or off, or steps through choices.

[option.Hat]
key     = "5"
default = "off"
on.show = ["Straw hat"]

[option.Hair]
choices    = ["Short", "Long"]
default    = "Long"
key        = "/"
Short.show = ["Hair 0"]
Long.show  = ["Hair 1"]

With no choices its choices are on and off, and it starts on unless its default is off. Two names that differ only in case are one switch; a name starting with @ is refused. A switch called Figure is never read by a condition, which reads her form instead.

Key What it does
choices The choices, in the order a press steps through them: all names or all numbers, never mixed. A name like 2 counts as a number.
default The choice it starts at, where not the first: one of its choices.
key The key that steps it, with modifiers: 5, Ctrl+Up; several in a list, the first shown. It fires only with exactly its modifiers held.
back The key that steps it back, or a list.
when While false, a press does nothing; what its choices show still draws.
name, group Its name on screen, and a heading to list it under.
names Names shown for numbered choices or on and off: { 0 = "Short" }. Ignored where choices have names.
wrap false: stepping stops at the last choice.

Keys: letters, digits, punctuation, F1 to F24, Numpad0 to Numpad9, Up, Down, Left, Right, Space, Enter, Tab, Backspace, Escape, Insert, Delete, Home, End, PageUp, PageDown, Pause, CapsLock, NumLock, ScrollLock, Add, Subtract, Multiply, Divide, Decimal, with Ctrl, Alt and Shift. Any other word or a second key, and it does nothing.

An import also writes kind (cycle, toggle, menu or detected), smart, drawn (the meshes its key works for), also (other values one press moves: variable, values, default), follows and does (drives or hides); you rarely need them.

A choice cannot be named like a key of the tables above (key, default, when): it would read as that key. A choice table missing from choices refuses the file. Rename a switch with Rename a switch, on a right-click of its row in Inside, so your saved pick follows it. On a mod imported from WWMI, a choice renamed by hand is refused.

#What a choice does

Key What it does
show The pieces drawn while chosen. A bare name is every piece of that name; 3/Name the one in part 3, by the part's key as written (skirt/Name).
wear.<part or piece> What a part or piece wears while chosen: a material's name, or a table of roles with an optional over (Which texture wins). * and 3/* are not allowed.
shapekeys Each shape key's weight: { 110 = 0.5 }; 0 at choices that leave it out.
scale The mesh's scale; 1 where left out.
opacity How see-through the pieces it shows are, as a piece's (Pieces). The lowest chosen wins, and the player's Opacity slider for the piece does nothing meanwhile.
outline The outline's scale. Not drawn yet.

#Looks: [look.<name>]

A look puts on several choices at once, from its key, the overlay or Timbre, and sets only what it names.

[look."Night out"]
key  = "F5"
Hair = "Long"
Hat  = false

[look.Swim]
key   = "-"
steps = [{ Top = "Bikini", Shoes = false }, { Top = "Shirt" }]
Key What it does
a switch's name A choice's name, a number, or true and false for an on-off switch. An unknown switch or choice is skipped.
steps One set of choices per press. A step may hold a when; a list in a step puts on the first entry whose when holds. A step whose when fails takes a press and sets nothing. Switches beside steps are ignored.
key, back, when, wrap, smart, drawn As a switch's. A wrong when is skipped, so the look always works.

A switch named like one of these keys cannot be set by a look. Where a switch or slider uses the same key, it takes the press.

#Conditions

A condition is a string in a when or a piece's cut. Single quotes need no escapes.

Written Means
Hair is Long, is not That switch is, or is not, at that choice
Hair in [Short, Long], not in It is, or is not, at one of those
Hat, not Hat An on-off switch is on, or off
and, or, not (…) and binds tighter than or; brackets group
<, <=, >, >=, ==, != The number behind a choice: a numbered choice's number, on 1 and off 0, and a named choice's WWMI value on an imported mod, else its place in choices, counting from 0
Figure is Ice, in, is not The character is in that form or not, by her forms' names; not a number. A form she lacks is never true; is not it is always true.
never Never true
a name from [when] That condition
  • Switch names match in any case; choice and [when] names exactly. is, in, and, or, not and never are lowercase. There is no always: leave the when out.
  • Quote a choice with a space: Outfit is "Night out". A switch's name cannot be quoted, so one with a space or bracket cannot be named in a condition.
  • A wrong or empty condition refuses the file in a switch's, rule's, piece's or mesh's when and under [when], used or not. In a look's, layer's or finish's when and a piece's cut it is skipped. A test of a variable no switch holds refuses it but in a look.

Name a condition under [when] to use it anywhere but inside another [when]; it hides a switch of that name.

[when]
bare_legs = 'not Socks and Skirt is Short'

#Parts and textures: [part.<n>]

A part is one section the game draws, by its number (Part 3 in Blender), written only where you say something of it.

[part.3]
diffuse   = "Textures/Body_D.dds"
normalmap = "game"

[part.skirt]
replaces = 4
diffuse  = "Textures/Skirt.dds"
Key What it does
a role What the part wears there (below).
replaces The part's number, where its key is a name. Required then, and it must be a number.
material A material its pieces wear where theirs says nothing. The part's roles win over it.
draws = "game" The game draws the part itself. Another value, refused.
mesh Its mesh, where the mod has several.
outline The outline's scale. Not drawn yet.

A part states what it wears all the time; what changes with a switch goes under a choice's wear or in a rule. A role written as a list refuses the file.

#Roles

Role In Timbre In game
diffuse Diffuse Drawn: the colours.
lightmap Light map Drawn. On a part laid on the game's UVs it keeps the game's channels that cut and fade the part.
normalmap Normal map Drawn: the bumps.
materialmap Material map Drawn.
highlight Highlight Drawn on hair.
fx FX map Read only by a piece's cut and a sheer mask. Without it, the piece draws whole.
glowmask, pattern, effectmask Glow mask, Glow pattern, Effect mask Effect texture.
matcap, ramp, sparkle, star Matcap, Ramp, Sparkle, Resonance star Effect texture.
hairuv, hairramp, hairnoise Hair UV map, Hair ramp, Hair noise Effect texture.
eyeglow, eyehighlight, faceshadow Eye glow, Eye highlight, Face shadow Effect texture.
wetnoise, noise, fur Wet noise, Noise, Fur Effect texture.
glow, cutoutmap, specialmap Glow in Paint Kept, never drawn, not even for your own shader.

diffuse, lightmap, normalmap, materialmap and highlight are drawn only where the game's draw of the part reads that kind of texture, else left out with no note. A role you leave out keeps the game's: give only a diffuse, and the light map and highlight stay the game's.

An effect texture is the game's picture for a shine, a sparkle, a glow or an eye's light on a part. A file in one replaces each of the game's textures of that role on that part, where the game's tables know them, and takes any value below; elsewhere the game's stays and the log says so. "#00000000" turns it off: a blank glow mask turns the glow off.

#Values

Value Means
"Textures/Body_D.dds" A file from the mesh's folder; a leading / starts at the mod's folder. One on another drive is never read.
"game" The game's own texture, over any material's.
"#rrggbb", "#rrggbbaa" A flat colour that replaces the texture, never tints. Drawn as linear: in a diffuse it looks lighter than in a paint program.
"neutral" Same as "game" for now.

Any other text, "none" included, is read as a file name.

File Drawn
DDS As stored: BC1 to BC7 (BC6H unsigned), R8, RGBA8, BGRA8, RGBA16, RG16, RGBA16F, R11G11B10F. Others and cube maps are not.
PNG, JPEG Uncompressed, up to 16384 pixels a side. Timbre builds the smaller sizes while the game is closed. A PNG marked sRGB reads as sRGB; others and every JPEG as linear, unless [color_space] says.
Anything else Not drawn: TGA, BMP, WebP.

A missing file draws the role blank, not the game's; one there but not drawable leaves the game's, and the log says why.

#Colour space: [color_space]

Where a PNG comes out too light or too dark, say how to read it, "srgb" or "linear", by its path in the mod.

[color_space]
"Textures/Skin_D.png" = "srgb"

#Materials: [material.<name>]

A named set of roles that parts, pieces and choices wear.

[material.leather]
diffuse   = "Textures/Leather_D.dds"
normalmap = "Textures/Leather_N.dds"

[material.leather_red]
over    = "leather"
diffuse = "#8a1010"

[piece.Buttons]
material = "leather_red"
Key What it does
a role As a part's; files start at the mod's folder.
over Where the roles it does not state come from: another material, game, neutral, or own for those of what wears it.
hlsl Your shader: one file for both stages, or { vertex = …, pixel = … }; a stage left out draws as the part does. A file beside the mod's folder starts with ... With only = true, what wears it is drawn by your shader or not at all, and casts no shadow.
inputs What it reads beside your textures, by the slot your ini names (ps-t11, pixel shader texture 11): a file, false, { game = "ps-cb4" } for the game's buffer, game and part for a game texture by its role, worn and a role for its own sheet in it, or file and format for data.
params The x, y, z, w values your ini sets (x200): a number, a switch, { time = 1 } for the clock, or rows by condition: the first that holds sets it, else 0.
blend "alpha", "add", "multiply" or "premultiplied", or a table of them by render target, as an ini's blend[3]. Another word skips it and its layers.
depth_write false keeps what is behind it visible.
depth The depth test, as an ini's depth_func: equal, less_equal, off and the rest.
write The channels of the first render target, as an ini's mask[0]: "rgb", or a table by target.
two_sided true draws both sides, as an ini's cull = none. Works without a shader too.
game_shader A game part whose shader draws it: { object = "galbrena", part = 15702 }. To ship that shader with the mod, add vertex, pixel and words (all three or none) and textures; in Inside this is Ship with the mod.

Which shader draws it. Overtone takes the first it has: the game_shader part's shader, shipped with the mod or kept on this machine from play; your hlsl once Timbre has compiled it on Windows; then the part's own. A material stating only blend, write and the depth keys does nothing.

game, neutral and own are built in. A [material.game], a name holding a / and an over that loops are skipped.

#Layers: [layer.<name>]

A material drawn again over a part or a piece, after it.

[layer.Oil]
on       = "Body"
material = "Oil"
when     = 'Oil is on'
opacity  = 0.85
Key What it does
on The part or piece it covers, the whole of it.
material Its material, which needs a shader Overtone draws (hlsl or game_shader); else the layer is not drawn and the log says so.
when While this holds; left out, always.
opacity 0 to 1, where the material has no blend.

#Rules: [[rule]]

What to wear while a condition holds that no one choice covers:

[[rule]]
when   = 'Colour is Red and Hat'
wear.3 = { diffuse = "Textures/Brim_Red.dds" }

when is needed, or the file is refused; wear.<part or piece> is as a choice's. Two rules, or a rule and a choice, that set one role of one thing under the same condition, or under conditions that overlap without one inside the other, refuse the file. Conditions that never meet, or one inside the other, are fine: the narrower wins. Two switches' wear tables clash the same way; where one wears a material by name, the switch written later wins.

#Masks: [[mask]]

A mod on its own UVs replaces, by name, its owner and a number, a mask an effect reads or one of several a word holds on a part, with file, when optional.

[[mask]]
name = "hiyuki 3"
file = "Textures/blank.dds"

name and file are required; an unknown name is skipped. It is worn only where the mod gives another texture.

#Which texture wins

A role is taken from the first of these that states it:

  1. A wear table of a choice or rule naming the piece, the narrowest condition first.
  2. A wear table naming the part, then the part's own roles.
  3. A material a choice or rule puts on the piece.
  4. A material a choice or rule puts on the part, then the part's material.
  5. The game's texture.
  • A piece's own material takes the part's place. Written in [piece] or given in Blender, it covers the part's roles and wear tables naming the part; with over = "own" they fill the roles it leaves out.
  • A material a choice wears replaces the part's material whole. A role neither it nor the part's own lines state is the game's.

#Renders: [render.<name>]

A texture the mod's shader draws, worn in place of the file replaces names, one for each set of switches the shader reads.

[render.Patterns]
replaces     = "Textures/main.dds"
hlsl         = "Shaders/Patterns.hlsl"
inputs.ps-t1 = [{ when = 'Socks is 0', value = "Textures/Socks.png" }]
params       = { x202 = "Socks" }
size         = [1024, 1024]
Key What it sets
replaces, hlsl The file it is worn for, and its shader for both stages. Both needed, or it is skipped.
inputs, params As a material's, or rows by condition. An input left out is what the part wears there.
size, srgb Its size, up to 16384, and whether it is sRGB; left out, the replaced file's.
vertices, topology, when Vertices drawn, as a list or strip (default: 4, as a strip), and when it draws.
unknown What an import could not read; a render reading one is not made.

#Pieces: [piece.<name>]

A piece is one object of the mod's model, by its name in Blender. It is drawn while every switch that shows it is at a choice that shows it and every when covering it holds. A piece nothing mentions is always drawn. Draw order cannot be set.

[piece."*"]
when = 'Outfit is not Swim'

[piece."skirt/Frills"]
opacity = { density = 0.5, mask = true }
Key What it does
when Drawn only while this holds too.
material Its material, in whichever part it is drawn.
cut Cut by its part's fx: true, false, or a condition.
opacity How see-through it is: a number, or density, mask and edge for sheer cloth (Make a piece see-through). The player gets an Opacity slider for it.
name Its name on screen.
outline The outline's scale. Not drawn yet.

[piece."*"] covers every piece and [piece."3/*"] part 3's, by the part's key as written. For cut, material and opacity the most particular wins: 3/Name, Name, 3/*, *. Every when among them must hold. A piece both cut and sheer is cut, and fades evenly.

#Hide the game's parts: [remove.<key>] 

[remove.6]

[remove.hair_accessory]
mesh     = "hair_accessory"
replaces = [0]

[remove.shadow]
underlayer = "skirt shadow"

[mesh.shadow]
when = 'Skirt is Short'

[remove.6] hides the game's part 6 of the mesh the mod draws. With a name as the key:

Key What it does
mesh Its mesh; left out, the one the mod draws.
replaces The parts it hides, a number or list. Without it, none.
underlayer A mesh of the game's worn under an outfit, by the exact name Mix shows, instead of mesh and replaces. Needs the mod's object, written or found. An unknown name hides nothing.

The game's parts under your own go by themselves; write a removal for a switch, or for parts your mod leaves alone. While its mesh's when fails, they stay (Meshes). [adjust.<key>], which keeps the game's parts with an outline or material of their own, is not drawn yet.

#Meshes: [mesh.<key>]

By its key: the mod's own folder is main, built from model.glb; another mesh from <key>.glb.

Key What it does
model Its .glb. Saving it in Blender rebuilds the mod.
scale Scales the whole mesh; not a number, ignored.
when Drawn, or its parts hidden, only while this holds.
folder The mod folder it came from; turning that off takes it away.

#Sliders: [slider.<name>]

A value that moves smoothly, such as a body shape.

[slider.bbs]
range  = [-0.2, 1.0]
key    = "Up"
back   = "Down"
rate   = 0.6
drives = [{ shapekey = 110 }]
Key What it does
drives { shapekey = 110 } or { mesh_scale = true }. Driving nothing, only a finish keeps it.
range Lowest and highest; left out, 0 to 1, or 0.1 to 5 for the mesh's scale alone.
default Where it starts, held in range; left out, 1 for the mesh's scale, else 0.
key, back Hold to raise and lower it; with stops, step it. One key each; a list's first.
rate How far a held key moves it a second. Left out, it crosses its range in a second.
stops Values a press steps through instead.

#Expressions: [expression.<name>]

A face made for the mod's character, offered while the mod is drawn (Wear an expression a mod ships).

[expression.Smirk]
keys  = { M_Smile_L = 0.8, B_Up_Add_L = 0.4 }
takes = 0.3

[expression.Playful]
keys   = { B_Happy = 0.6 }
varies = [{ to = "Smirk", every = [6, 14], hold = 0.5 }]

[expression.Peek]
steps = [{ keys = { T_Out = 0.4 }, takes = 0.3, hold = 0.5 }, { to = "Smirk" }]
Key What it does
keys Her face's shape keys by the game's names, the same on every character (E_Close_L, M_Smile_L), each 0 to 1. Her tongue: T_Out, curled by T_Down, T_Up, T_Left, T_Right; T_Lip lays its tip on her lip.
takes Seconds it eases in over; left out, 0.2.
varies A mood: it drifts to the expression to names and back, at a random time between every's two seconds, shorter first, staying hold seconds (left out, 0.3). to is looked for among yours, a drawn mod's, then the game's; it cannot be a mood.
steps A sequence: each step the expression to names or its own keys, not both, reached in takes (left out, 0.2) and held hold (left out, she does not stop there). The expression's keys lie under every step. A to never names a mood or a sequence; varies and steps never together.
ends After the last step: stop (left out) stays, loop goes on to the first, turn plays back and forth.

No keys or steps, a weight past 0 to 1, a key twice or ends without steps skips it, its line logged; past 256 keys, drifts or steps in one, or 256 expressions in a mod or for a character, the rest are skipped.

#Finishes: [finish.<name>]

Oil, chrome or another sheen on the mod's parts.

[finish.oil]
like     = "oil"
on       = ["Body/*", "Legs"]
where    = "skin"
strength = "Oil"
when     = 'Wet is On'

[finish.pearly]
shine = { gloss = 0.7, metal = 0.1, colour = "#f4eee8", coat = { gloss = 0.95 } }
mask  = "Textures/Pearl.dds"
Key What it does
like A shipped finish: oil, wet, sweat, chrome, pearl, satin, latex, glitter, gem.
shine A matcap of the mod's, or gloss and metal 0 to 1, colour and a coat; over a like's.
colour, strength A tint, white; how strong, 1, or a slider's name.
blend, where add (default), screen, multiply, over; skin, clothes, metal, everywhere (default).
on, mask, when Parts and pieces as show names them, else all; a texture whose red says how much; a condition.

A name the mod lacks, Figure or a part's ninth skips it, as do layers; rim, sparkle, normalmap, patches, flow and darken are skipped alone.
