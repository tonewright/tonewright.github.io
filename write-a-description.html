Write a description

Change a mod's description by hand: switches with several choices, textures that change with a switch, conditions, looks, the game's parts hidden, sliders, expressions and layers.

How-to8 min readTimbre 26.1123.0 · Overtone 26.1123.0

A mod's description, overtone.mod.toml, says what its switches show and wear. Timbre writes one for every mod it imports or dumps. Edit it to add what an import can't: more choices, keys, looks. Coming from WWMI ini files:

  • Names, not hashes. Pieces go by their names in Blender and switches by names you choose; there is no buffer, hash or variable to track.
  • Tables, not scripts. A switch is one table of choices, each listing what it shows; no if blocks to follow.
  • Mistakes marked as you type. Timbre underlines a wrong line with a note, and refuses to save a file that would not draw.
  • No reload. A saved change shows in game a moment later.

Every key and value is in the Description reference; this guide shows how they fit together.

#Before you start

  • A mod in your library that Timbre has imported (Add mods) or dumped. How to create a mod covers making a piece switchable and swapping a texture.
  • The game running with the mod on screen, to see each change.

#Your first change

Give an existing switch another key.

  1. In Timbre, open the mod's page and its Inside tab. Its switches are listed.
  2. Click a switch's row. The description opens beside it at that switch, with a line such as key = "5".
  3. Change "5" to "Alt+5".
  4. Press Ctrl+S. The change is saved; a mistake would be underlined instead.
  5. In game, press Alt+5. The switch steps. 5 alone now does nothing, since a key fires only with exactly its modifiers held.

#How a description decides what you see

  • Pieces and parts. A piece is an object of yours, named as in Blender. A part is a section of the character the game draws, known by its number (Part 3 in Blender and in Timbre's Model). A piece nothing mentions is always drawn.
  • Switches and choices. A switch sits at one choice at a time. Each choice lists the pieces it shows and what parts or pieces wear while it is chosen. Your pick is kept beside the mod, so the description says only where it starts.
  • Conditions. Where one switch is not enough, a condition combines switches. Write it in a piece's when or a rule, or name it under [when] (Conditions).

#Give a piece several looks

A switch with choices steps through them in order. Here / steps the hair from short to long to braided and back; Alt+/ steps it the other way.

[option.Hair]
name       = "Hairstyle"
choices    = ["Short", "Long", "Braid"]
default    = "Long"
key        = "/"
back       = "Alt+/"
Short.show = ["HairShort"]
Long.show  = ["HairLong"]
Braid.show = ["HairBraid", "Ribbon"]
  • Each piece is drawn only at the choices that show it, so Ribbon shows only with the braid.
  • It starts at default; the overlay's Wardrobe and Timbre show it as name.
  • Set wrap to false to stop it at the last choice instead of going round.
  • A switch with no choices is on or off: write what it shows under on, and set default to off to start it off.

#Change textures with two switches

A choice's wear changes what a part wears while it is chosen (Swap a texture). Where a texture depends on two switches, write a rule for that combination. Here Dye recolours the jacket, part 3, and its buttons, and a rule gives the gold jacket another file while the hood is up:

[option.Dye]
choices           = ["Plain", "Gold"]
key               = "8"
Gold.wear.3       = { diffuse = "Textures/Jacket_Gold_D.dds" }
Gold.wear.Buttons = { diffuse = "Textures/Buttons_Gold_D.dds" }

[option.Hood]
key     = "7"
on.show = ["Hood"]

[[rule]]
when   = 'Dye is Gold and Hood'
wear.3 = { diffuse = "Textures/Jacket_Gold_Hood_D.dds" }
  • Naming a piece, Buttons, changes that piece alone; naming a part, 3, changes every piece in it.
  • The narrower condition wins, so with the hood up the gold jacket wears the rule's file.
  • If two switches set part 3's diffuse in tables and both can be on at once, the file is refused. Let one switch set it, and write each combination as a rule like this one (Which texture wins).

#Show a piece only when two switches agree

With on-off switches Socks and Skirt, give the condition a name under [when], then hold the piece to it:

[when]
bare_legs = 'not Socks and Skirt is Short'

[piece.Tattoo]
when = 'bare_legs'

Tattoo is drawn only while the socks are off and the skirt is short. A piece named by both a when and a switch's show draws only when both allow it. [piece."*"] holds every piece to a condition, and [piece."3/*"] every piece of part 3.

#Put on a whole outfit with one key

A look sets several switches with one press. It sets only what it names; the rest stay where they are.

Here Top is a switch with the choices Bikini and Coat, and Shoes an on-off switch:

[look.Beach]
key   = "F5"
Top   = "Bikini"
Shoes = false
Hair  = "Braid"

[look.Weather]
key   = "F6"
steps = [{ Top = "Coat", Shoes = true }, { Top = "Bikini" }]

F5 puts on the beach look. F6 steps through steps, one per press: the coat and shoes, then the bikini. Looks are also listed in the overlay's Wardrobe under the mod.

#Hide one of the game's parts

Overtone already hides the game's parts your pieces replace. To hide one your mod leaves alone, name its number:

[remove.6]

To hide a mesh the game wears under an outfit, such as a skirt's shadow, only while a switch allows, use the name Mix shows it under:

[remove.shadow]
underlayer = "skirt shadow"

[mesh.shadow]
when = 'Skirt is Short'

The [mesh] table with the same key, shadow, holds the condition. While it fails, the game's mesh stays.

#Make a body-shape slider move smoothly

A WWMI mod that changes her shape gets a slider when imported. Give it keys that move it while held:

[slider.Chest]
range   = [0.0, 1.0]
default = 0.0
key     = "Up"
back    = "Down"
rate    = 0.5
drives  = [{ shapekey = 110 }]

Holding Up raises it by rate a second, half its range here; without rate it crosses the range in a second. Write stops = [0.0, 0.5, 1.0] instead to step it a press at a time. The overlay's Wardrobe shows it as a slider too.

#Give her an expression

An expression is a face for the mod's character, offered while the mod is drawn (Wear an expression a mod ships). Its keys are her face's shape keys by the game's names, as Timbre's Expressions page lists them under Shape keys. Here Wink closes her left eye and half smiles:

[expression.Wink]
keys  = { E_Close_L = 1.0, M_Smile_L = 0.5 }
takes = 0.2

[expression.Cheeky]
keys   = { B_Happy = 0.4 }
varies = [{ to = "Wink", every = [8, 20], hold = 0.4 }]

[expression.Chew]
steps = [{ keys = { A = 0.3 }, takes = 0.25 }, { keys = { M_Nutcracker = 0.4 }, takes = 0.25 }]
ends  = "loop"
  • Wink eases in over 0.2 seconds and stays.
  • Cheeky is a mood: every 8 to 20 seconds she winks for 0.4 seconds and goes back.
  • Chew is a sequence: she plays its steps and, since its ends is loop, starts over.

The top of the file must name her object, or the mod offers none.

#Add a wet or oil layer

A layer draws a second material on top of a part or piece, with a shader your mod ships. Here it lays a sheen on the body while an on-off switch called Oil is on:

[material.sheen]
over        = "own"
hlsl        = { pixel = "Shaders/Oil.hlsl" }
blend       = "alpha"
depth_write = false
depth       = "equal"

[layer.Oil]
on       = "Body"
material = "sheen"
when     = 'Oil'

Timbre compiles the shader on Windows; until then the layer is not drawn, and the log says why. A layer whose material has neither an hlsl nor a game_shader is never drawn. Writing the shader itself is Draw with your own shader.

#Fix what an import wrote

Timbre writes the description of a WWMI mod from its ini files. Where that is not enough:

Case What you see Fix
A switch is named after the ini's section A name such as Legs that says little Add name, or right-click its row in Inside for Rename a switch
Its choices are numbers 0, 1, 2 in the Wardrobe Add names, a name for each number
A slider moves too fast or too slow while its key is held It overshoots, or crawls Change rate, how far it moves a second
An update changed what you changed It is listed under Changed by you and the update Pick Yours or Update for each, then Apply

#What you can't do yet

  • Add a part or a shape key. Only the game's own parts and her own shape keys can be used (Edit a mod in Blender).
  • Give a part a glow of its own. glow is kept but never drawn; a glowmask changes where the game's glow shows.
  • Change the outline. Every outline is kept and not drawn yet.
  • Set the order pieces are drawn in. It is the model's.
  • Make a slider that only your shader reads. A slider that moves no shape key or scale is ignored.
  • Give a slider two keys. A slider takes one key and one back; of a list, only the first works.
  • Draw a mod of a game Overtone does not draw yet. Its description is read and edited, never drawn.
