Make a piece see-through

Make a piece or part of a mod see-through, the same all over or as sheer cloth, and move it with a slider of its own.

How-to7 min readTimbre 26.1123.0 · Overtone 26.1123.0

Make stockings, a veil or a visor see-through. One line in a mod's description does it, and you can write that line on any mod, yours or someone else's:

  • Only what you name changes. The rest of the mod stays solid.
  • No export, no ini. You save a text file and see it in game a moment later.
  • A slider for each thing you made see-through. It appears in Timbre and the overlay. A mod that states nothing has none.
  • Cloth, not a ghost. Sheer cloth lets what is behind show through its gaps, and stays lit like cloth.

#Before you start

  • The mod is in your library and draws in game (Add your mods).
Word Means
part One section of the character the game draws, such as hair or body: Part 3 in Timbre's Model
piece One object of a part, by its name in Blender
description overtone.mod.toml, the mod's settings file
fx texture A texture a part can wear as a mask, read for its alpha

#Your first see-through part

This makes one whole part half see-through.

  1. In Timbre, open the mod's Model. Each part is headed by its number, such as Part 3 or Face · Part 2. Pick one.

  2. Open the mod's Inside.

  3. Click a row. Its description opens beside it.

  4. Add this at the end of the file, with your part's number:

    [piece."3/*"]
opacity = 0.5

    If the file has a heading for that part by name, such as [part.skirt], write that name for the number: [piece."skirt/*"].

  5. Press Save. In game, that part is half see-through a moment later.

  6. Press Home. The overlay opens.

  7. In Wardrobe, open the mod's row. A slider Part 3 · Opacity stands at 0.5.

  8. Drag it to 1. The part is solid again, and the rest of the mod never moved.

#A number or a table

opacity takes a number or a table. Both draw the piece as the game fades a character up close: a fine pattern of dots, so what is behind shows through the gaps and the piece stays lit as itself. The table says more.

A number: opacity = 0.5 A table: opacity = { density = 0.5 }
How see-through The same all over density all over, or less where a mask says, and more at the edges with edge
Up close Dots, in nine steps from thin to dense The same

Both run from 1, solid, down to 0. At 0 the piece is gone and has no slider.

#Choose what it covers

The heading says what the line covers, and names the slider.

Heading Covers Slider
[piece."3/Frills"] The piece Frills in part 3 Frills · Opacity
[piece.Frills] Every piece named Frills Frills · Opacity
[piece."3/*"] Every piece of part 3 Part 3 · Opacity
[piece."*"] Every piece of the mod Opacity
  • The narrowest heading wins. A piece with a line of its own keeps its own slider, and its part's slider does not move it.
  • A heading the file already has takes the line under it. Don't write the same heading twice.
  • A slider can go by another name. Add name = "Lace" under the piece's heading.

#Make cloth sheer

Key What it does Default
density How much of the cloth is there, from 0 to 1 1
mask true reads how much is there at each pixel from the alpha of the part's fx texture false
edge From 0 to 1, how much denser the cloth gets where it turns away from you, as woven cloth does at 1 0

#Paint where it is thin

  1. In an image editor, open the diffuse texture of the piece, so what you paint lies where the piece does.

  2. Paint the alpha channel: opaque where the cloth is whole, transparent where it is open.

  3. Save it in the mod's folder as a DDS in BC7 or BC3, for example Textures/Skirt mask.dds.

  4. In the description, add the texture to the part's heading and the mask to the piece:

    [part.3]
fx = "Textures/Skirt mask.dds"

[piece."3/Skirt"]
opacity = { density = 0.8, mask = true, edge = 0.5 }

  5. Press Save. In game, the skirt is open where you painted it open, and 0.8 dense where you left it whole.

A part has one fx texture, for all its pieces. Each piece still has its own density.

Sheer is not always possible:

The piece What you get Do this
Is also cut out by the mask (cut) The cut wins and the piece fades flat Write cut = false on the piece
Has mask = true, and its part has no fx Sheer at its density, the same all over Add fx to the part
Has a mask saved as BC1 Each pixel all there or not at all Save it as BC7 or BC3
Is drawn in a shader the mod ships, its own drawing code A flat fade at its density Leave its shader out

#Change it with a switch

A choice can say how see-through the pieces it shows are. This is what a mod's author does for a thin and a thick version:

[option.Stockings]
choices       = ["Thick", "Thin"]
key           = "6"
Thick.show    = ["Stockings"]
Thin.show     = ["Stockings"]
Thin.opacity  = { density = 0.3 }
  • The choice wins over the piece's own line while it is chosen. Where two chosen choices say it, the lowest wins.
  • A choice's opacity has no slider: the switch is its control.

#Move the slider

The slider is under the mod's row in the overlay's Wardrobe, and in the mod's Variants in Timbre.

  • It starts at what the description says, and runs from 0.1 to 1. A description below 0.1 lowers the bottom to its own value.
  • On a table it moves density. The mask and edge stay as written.
  • Your value is kept with the mod when you let go, and an update of the mod keeps it.

An imported WWMI mod that is see-through in places shows that as it always did, with no slider. Write an opacity for that piece to get one.

#When it does not look right

A line that cannot be used is marked beside it in Inside, and says why.

You see What it means Do this
opacity = 1.5 is not a number from 0 to 1 The value is out of range Write a value from 0 to 1
Skirt is cut and sheer, so the cut wins and it fades flat The piece is cut, by this file or by the mod's import Write cut = false on the piece
Stockings Thin states opacity and shows no piece, so it fades nothing That choice shows nothing Add the piece's show to every choice that should draw it
[piece.3/*] names no piece The mod has several meshes, or the part has a heading by name Use the part's name, or name the piece outright
No slider The line says 0, or a narrower heading covers every piece Check the headings
The slider moves nothing A switch's choice is saying the opacity Leave that choice, or change it in the description
The slider moves nothing, on a part that is already see-through The game, or the mod's own settings, blend it their own way Nothing: it keeps its own strength
The piece is missing See-through parts is off Parts flicker, stretch or vanish

#What you can't do yet

  • Make the game's own parts see-through. Only a mod's own pieces.
  • Give the slider a key. It moves by dragging.
  • Keep a slider's value in a loadout or a shared mod. Those start at what the description says. Write your value into the description to send it.
  • See the slider in Timbre's Model. It shows what a piece's own line says, not the slider or a choice.
  • See through a [layer]. One drawn over a sheer part covers its gaps.
  • Take the outline off a see-through piece. It keeps the game's outline.
  • Fade a piece smooth, as glass. A number draws dots too.
